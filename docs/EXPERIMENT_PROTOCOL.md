# 实验协议

## 目录结构

```text
shared/experiments/{research_name}/exp_XXX/
```

每个实验应包含：

```text
result.csv
meta.json
strategy.py
validation_report.json
metrics.json
trades.csv
equity_curve.csv
validation.json
```

## `meta.json` 约定

必须包含：

- `experiment_id`
- `strategy_name`
- `research_name`
- `description`
- `status`
- `metrics`
- `validation`

`metrics` 至少记录 `rows`、`max_return`、`min_return` 和 `alert_count`。

`research_name` 用于目录隔离，按核心研究方法命名，而不是机械复用当前策略名。均线/EMA 研究应使用 `moving_average`，动量研究应使用 `momentum`。一次实验只能归属于一个研究方向。

## 回测输出

`result.csv` 至少记录：

- 日期
- 板块名称
- 下一交易日收益
- 累计收益

`next_return` 统一定义为：在当日收盘根据信号完成交易后，持仓组合在下一交易日收盘产生的收益。最后一个交易日没有下一交易日收益时，不纳入收益序列。

## 分析指标

所有实验必须使用统一结果分析口径，至少输出：回测区间、结果行数、累计收益、最终净值、年化收益率、最大回撤、年化波动率、夏普比率、卡玛比率、胜率、平均收益、盈利/亏损/持平日数、最大连续亏损天数、平均/最大持仓数、空仓比例、异常收益数、缺失收益数、非法收益数、日期排序状态和重复记录数。

其中胜率和平均收益默认指日度组合收益口径。逐笔交易胜率、平均盈利、平均亏损、盈亏比必须基于独立的逐笔交易记录，不能从日度组合收益直接推导。

结果分析统一由 `strategy_lab/result_analysis.py` 实现，禁止各策略自行定义同名指标的不同算法。

## 成本规则

交易成本统一采用单边 0.10%（买入或卖出各 0.10%，买卖合计 0.20%）。无交易不扣成本；首次建仓和最终平仓均属于交易。成本按实际交易资金权重计入组合收益。

## EMA 与组合口径

- EMA 按板块独立计算，`min_periods` 等于 EMA 周期；最长 EMA120 有效前不产生信号。
- 同时满足条件的板块等权持有，不因其他板块信号变化而强制再平衡。
- 空仓期间组合收益为 0；最后一个交易日按收盘价记录未平仓头寸。

## 校验报告

校验报告必须检查文件和字段完整性、数据重复/缺失、日期排序、收益边界、信号时序、持仓状态、EMA 初始化和索引与元数据一致性。

## 实验结论

每轮实验应记录策略假设、参数变化、结果和是否进入下一轮。

## 两层职责与交互流程

Python实验计算层负责数据读取、信号计算、回测、指标统计、交易明细、资金曲线和数据校验，只输出客观事实。

云端AI分析层负责理解实验目的、解释统计结果、进行父子实验比较、识别风险和提出下一步实验建议，不重新猜测或修改Python统计结果。

标准流程：

1. 用户确认实验规则并要求开始回测。
2. Python完成回测并保存标准结果集。
3. 回测完成后先向用户汇报结果，询问是否进入分析阶段。
4. 用户明确回答“是”后，才按统一分析框架进行解释和研究建议。
