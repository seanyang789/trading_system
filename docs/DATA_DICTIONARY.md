# 数据字典

## 数据文件

文件：`shared/data/bk.csv`  
用途：板块历史行情数据，用于按板块计算技术指标和回测收益。  
编码：GBK  
记录数：69,384  
日期范围：2021-08-02 至 2026-09-09  
板块数量：56  
板块代码数量：56  
缺失值：当前检查的 9 个字段均为 0

## 字段定义

| 原始字段 | 清理后字段 | 类型 | 用途 | 缺失要求 |
|---|---|---|---|---|
| 日期 | 日期 | 日期 | 回测时间轴、排序和信号日期 | 不允许 |
| 板块编码 | 板块编码 | 文本/标识符 | 标识板块，适合关联其他数据 | 不允许 |
| 板块名称 | 板块名称 | 文本 | 分组、排名和信号识别 | 不允许 |
| 开盘 | 开盘 | 数值 | 开盘交易或开盘收益计算 | 不允许 |
| 最高 | 最高 | 数值 | 区间波动和高点分析 | 不允许 |
| 最低 | 最低 | 数值 | 区间波动和低点分析 | 不允许 |
| 收盘 | 收盘 | 数值 | 日收益、动量和均线计算 | 不允许 |
| 成交量 | 成交量 | 数值 | 流动性和成交量过滤 | 不允许 |
| 成交额 | 成交额 | 数值 | 流动性和资金规模分析 | 不允许 |

原始文件中部分字段名前带有空格。读取后应执行列名清理，例如 `收盘`、`最高` 和 `成交量` 应按清理后的名称使用。

## 数据约定

- `日期 + 板块编码` 应唯一标识一条板块行情记录。
- 当前数据中板块代码和板块名称均各有 56 个唯一值。
- 日期应转换为日期类型后再排序。
- 价格字段应为正数，不能使用缺失或非法值计算收益。
- `成交量` 和 `成交额` 的具体计量单位以数据源定义为准，当前文件未单独提供单位元数据。
- 回测前按 `板块名称 + 日期` 排序，避免分组收益计算错序。

## 当前回测使用字段

`current_strategy.py` 当前使用：

- `日期`
- `板块名称`
- `收盘`

其他字段已登记，可供后续均线、波动率、流动性和开盘交易实验使用，但未经实验明确要求不会自动加入策略逻辑。
