# 四、当前系统不足

当前系统主要关注：

策略最终收益。

缺少：

## 1. 信号级分析

无法回答：

某一次买入信号历史成功概率。

需要增加：

- 买入信号统计
- 未来收益统计
- 胜率统计
- 盈亏比统计

## 2. 条件组合研究

当前：

策略逻辑主要写在代码中。

需要支持：

人工提出：

A条件

-

B条件

-

C条件

然后验证组合效果。

## 3. 风险分析深化

需要增加：

- 最大不利走势(MAE)
- 最大有利走势(MFE)
- 连续亏损
- 风险退出统计
