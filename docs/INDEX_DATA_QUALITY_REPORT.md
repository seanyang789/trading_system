## 脏数据特征与判断

1. **空行情占位行**：已由通用质量门禁隔离，不再进入正常分析。
2. **close-only 历史行**：个别指数早期只有收盘价，不能用于完整K线策略；保留但必须过滤 `is_valid_ohlc=false`。
3. **零成交量/成交额**：指数口径中较常见，不自动判定为错误，但不得直接用于流动性、VWAP或成交量因子。
4. **极端涨跌**：早期指数可能存在制度变化、基期或历史重编导致的大波动，先标记、再核对公开来源，不自动删除。
5. **日期缺口**：周末和节假日是正常非交易日；连续超过10个自然日才作为异常候选，不能简单按自然日逐日要求。
