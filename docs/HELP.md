# Strategy Lab Help

在项目根目录执行：

```text
python help.py
python help.py 更新数据
python help.py --search 质量
```

## 数据指令

| 指令 | 指令内容 |
|---|---|
| `检查数据` | 检查当前回顾数据是否存在缺失、重复或明显异常 |
| `更新数据` | 同时检查日线和分钟线，但分别判断是否出现新交易日；日线有更新不代表分钟线有更新，分钟线有更新也不代表日线有更新。对应频率没有新交易日就立即停止该频率的更新；旧交易日数据被修改，不视为新数据。 |
| `更新日线` | 从通达信 vipdoc 增量更新当前回顾数据 |
| `重建日线` | 从通达信 vipdoc 重新构建当前自定义板块回顾数据 |
| `整合分钟线` | 将指定代码的分钟数据整合为回顾数据 |
| `检查分钟线` | 统计分钟数据中的缺失、重复、错位和疑似脏数据 |
| `构建分析数据库` | 按代码和年份拆分数据，构建高效回顾数据库 |
| `检查分析数据库` | 检查分析数据库的完整性和质量门禁结果 |
| `构建指数分钟数据库` | 从通达信 vipdoc 读取 6 个指数分钟线，按代码和年份保存为 Parquet，并生成质量报告 |

## 研究指令

| 命令 | 作用 |
|---|---|
| `查看买点` | 按照指定研究规则重新计算指定标的的全部买点 |
| `查看卖点` | 按照指定研究规则重新计算指定标的的全部卖点和对应交易结果 |
| `生成通达信买点公式` | 将已经梳理出的买点日期生成完整可执行的通达信主图公式 |
| `运行回测` | 按照当前研究规则运行历史回测并保存实验结果 |
| `查看实验` | 查看已有实验、实验指标和实验状态 |
| `删除实验` | 在确认后删除指定实验及其索引记录 |
| `系统状态` | 查看当前系统阶段、数据入口和已知限制 |

## 通达信公式指令

当你已经让我梳理出买点或卖点时，可以直接说：

```text
生成通达信买点公式
```

如果指定标的，可以说：

```text
查看 000300 的买点，并生成通达信买点公式
查看 某板块 的卖点
```

买点公式输出必须包含完整公式、全部日期条件和对应的 K 线标记，不能用省略号或“其余日期略”。当前系统已经支持买点公式；卖点可以计算和展示，但还没有独立的卖点公式生成指令。

## 推荐工作流

1. `检查数据`
2. `更新数据` 或按需使用 `更新日线` / `构建指数分钟数据库`
3. `运行回测`
4. `查看买点` / `查看卖点`
5. `生成通达信买点公式`
6. 回测结束后先看客观结果，再决定是否进入分析阶段。

## 数据边界

- `shared/data/数据源` 是原始数据，原则上只读。
- `shared/data/bk.csv` 是当前回顾入口，不应和原始数据更新逻辑混用。
- `shared/data/analysis_db` 是分析数据库，不替代原始数据。
- 历史实验结果不能覆盖；删除实验必须明确确认。

## 常见问题

不知道系统有哪些命令：`python help.py`。

只想找某个功能：`python help.py --search 复权`、`--search 分钟` 或 `--search 实验`。

发现数据没有更新：检查 vipdoc 路径和对应频率的源文件最新交易日期。`更新数据` 会分别检查日线和分钟线；旧交易日的文件变化不会被当作新交易日，且日线更新不会触发分钟线更新。

## 维护规则

每新增一个用户可调用脚本、快捷自动化或改变一条数据链路，必须同时更新：

1. `help.py` 的命令索引；
2. 本文档对应章节；
3. `docs/CURRENT_STATUS.md`（如果改变系统状态）；
4. `docs/DECISION_LOG.md`（如果改变设计决策）。

如果发现用户反复询问某个用法，或系统新增了实际可运行但文档没有覆盖的功能，应主动补充本文档，不等待再次提醒。

每次回测结果需展示固定统计区间；衍生分析沿用父实验区间和输入快照。旧实验没有源版本记录时，会提示版本未知；若当前数据已更新且旧实验无快照，不会继续混用数据。

正式回测可指定固定区间，例如：

```text
运行回测 --start-date 2024-01-01 --end-date 2025-12-31
```

随后执行买点衍生分析时，引用父实验编号，系统会继承其区间和输入版本；无法确认旧实验数据版本时会明确提示。

## 当前待核查项

- 复权数据应保留原始不复权数据、事件数据和计算结果，避免无法追溯。
